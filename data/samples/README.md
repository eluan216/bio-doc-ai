# Sample Medical Documents

This folder contains open-access medical research papers for demonstration purposes.

**Instructions:**
1. Download open-access PDFs from:
   - PubMed Central: https://www.ncbi.nlm.nih.gov/pmc/
   - arXiv: https://arxiv.org/ (search: medical, biomedical)
   - bioRxiv: https://www.biorxiv.org/

2. Place PDFs in this folder for the "Load Sample Document" feature

**Example searches:**
- "COVID-19 clinical outcomes" (PubMed Central)
- "Machine learning healthcare" (arXiv)
- "Biomarker discovery" (bioRxiv)

Sample PDFs will be automatically available in the Streamlit sidebar.
